# 配置与使用

## 模型连接

填写 API 根地址，例如 `https://api.deepseek.com` 或服务商提供的 `https://example.com/v1`。不要填 `/chat/completions`、`/models`、`/responses` 终点，也不要把 Key 放在 URL 中。只有本机接口可以使用 HTTP；远程服务需要 HTTPS。

文字模型需要支持 Chat Completions；PPTX 视觉模型还需支持图片输入。二者可以是不同服务。只有确认同一模型支持图片时才选择“复用上方文字连接”。

获取列表时只需要地址和 Key，不必先填模型名。列表为空、接口不支持或缺少模型时手填，再分别测试文字/视觉。列表成功仅证明能列出模型。

默认示例是 DeepSeek；只有官方根地址或官方 `/v1` 路径可以读取环境变量 `DEEPSEEK_API_KEY`，不会把这个环境变量转发给自定义服务。普通使用者直接在网页配置即可。

JSON 模式会发送 `response_format` 参数；服务不支持时可以关闭，但结果仍必须是完整 JSON 并通过 Schema 与引用检查。

对精确 DeepSeek 官方根地址的 `deepseek-flash` / `deepseek-v4-pro`，结构化任务显式设置 `reasoning_effort=low`，连接探测使用 `none`，避免短探测或结构化输出被默认高强度思考挤占。审核初始输出上限 13,000 tokens，其他节点 6,500；明确截断时官方模型重生成额度有界增加，最高 26,000。中转、其他路径和未知模型保持基础参数，不自动发送这些扩展。依据：[思考模式](https://api-docs.deepseek.com/guides/thinking_mode)、[接口定义](https://api-docs.deepseek.com/api/create-chat-completion)。

## 并发与预算

并发可选 1–8 路，默认 2 路。选择后自动保存非敏感设置到 `data/settings.json`。新任务保存提交时的快照；正在运行的任务不跟随偏好变化。

整个服务实例内的生成、模型列表及连接测试共用限额；其他程序或其他服务实例不在此范围内。提取节点可并行，出题与制卡可并行，但视觉识别和审核仍逐批进行，并发上限不代表每个阶段都发满。

HTTP 429 可能由并发、每分钟请求/token、共享池、余额或额度造成。本项目不主动压测服务上限；按照供应商限制调低并发。网络或 HTTP 错误不自动重试，已经发出的请求可能产生用量。

任务总请求预算默认 120、可设 1–200。分批、格式修正与审核拆分都计入预算。预览显示最低请求数及保守上限；达到预算停止，预算不是价格报价。

## 文档与范围

- 最大 50 MiB，PDF/PPTX 最多 200 页；单次选中最多 60,000 字符、24 个文字段。
- 页码按原文件的物理页序，例如 `1-8,12`，输入后更新预览。PPTX 另有 24 张整页图的独立限制。
- PDF 只提取文字；纯扫描件提示 OCR 尚未支持，混合资料会列出无文字页。
- PPTX 会读取文字、表格、组合形状和可读取的内嵌图表数据，并识别选中页整页图。备注、动画过程及视频不纳入；旧 `.ppt` 需另存 `.pptx`。
- PPTX 前先保存并关闭所有 PowerPoint 窗口。渲染最多 120 秒，程序不自动关闭已有用户实例；只清理能证明由本次任务创建的进程。
- 出题/制卡按数量抽样复习；审核可以删除证据不足内容，最终数量可能较少。

## 历史与导出

原文件、结果和 SQLite 历史在 `data/`；不要让两个实例同时使用一个数据目录。单实例同时运行一个完整任务，可另有两个排队。程序退出后没有自动续跑，重启会把未完成任务标为中断，成功历史保留。

Word 为真正的 `.docx`，包含笔记、题目与答案解析、卡片、出处和审核；Markdown 适合继续编辑；Anki TSV 是正面/背面两列，可在导入时允许 HTML 换行；JSON 保留完整结构和安全诊断，适合程序继续处理。

保存连接使用 Windows 当前用户 DPAPI。加密文件不能作为跨机器备份；在受限会话无法解密时，请用原 Windows 用户在自己的 PowerShell 启动，不要关闭系统安全设置。

## 常见问题

| 现象 | 排查 |
| --- | --- |
| 无法识别 Python 路径 | 确认在仓库根目录，且 `.venv` 已创建；路径有空格时加引号并用 PowerShell `&` 调用 |
| 端口占用 | 停止同项目旧后台，或加 `--port 8766`；不要只刷新网页期待重载 Python |
| 模型列表不可用 | 手填模型名，核对 API 根路径；列表不是必需接口 |
| HTTP 401/403/404 | 分别核对 Key/权限、服务区域与地址/模型名；不是都由代理造成 |
| HTTP 429 | 核对余额、额度和速率限制，再调整并发 |
| 格式修正失败 | 检查错误中的字段位置，尝试兼容性更好的模型或缩小资料范围 |
| 输出长度截断 | 审核会自动拆批；单条仍失败或预算达到时停止，不交付残缺结果 |
| Office 自动化失败 | 确认 Microsoft PowerPoint 可正常启动、没有既存实例，并在正常用户会话运行；WPS 暂不支持 |

可分别执行本地自检，不调用模型：

```powershell
& .\.venv\Scripts\python.exe -X utf8 .\app.py --render-self-test
& .\.venv\Scripts\python.exe -X utf8 .\app.py --encryption-self-test
```

渲染自检会启动本机 PowerPoint，请先保存并关闭它。
